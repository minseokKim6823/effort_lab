Effort Lab v0.2.0 — 독립 작업 묶음 실행과 측정 무결성 개선

[README와 설치 방법](https://github.com/minseokKim6823/effort_lab#다운로드와-시작) · [측정 방법](https://github.com/minseokKim6823/effort_lab/blob/main/docs/측정방법.md) · [실측 데이터와 재현 기록](https://github.com/minseokKim6823/effort_lab/tree/main/results)

- 독립 작업을 최대 4개씩 묶어 같은 high effort로 실행합니다. 반복되는 입력 문맥을 공유하며, 작업별 답안과 호출별 전체 사용량을 함께 확인합니다.
- 같은 24개 합성 문제에서 개별 high 24회와 네 문제씩 묶은 high 6회가 모두 24/24 정답이었습니다. 전체 토큰은 95,440에서 32,665로 **65.77% 감소**했습니다. [측정 조건과 원본](https://github.com/minseokKim6823/effort_lab/blob/main/docs/묶음실측결과.md)을 공개합니다.
- 같은 문제의 후속 개별 low 24회는 98,979토큰·19/24 정답으로 개별 high보다 3.71% 많은 토큰을 쓰고 5문제를 더 틀렸습니다. [후속 결과](https://github.com/minseokKim6823/effort_lab/blob/main/docs/개별-effort-후속결과.md)를 공개합니다. 낮은 effort를 기본 성과로 주장하지 않습니다.
- 정답과 검증 규칙은 모델 프롬프트에 넣지 않습니다. 묶음 답안의 작업 ID·중복·누락과 JSON 형식을 검사하고, 오류가 나도 이미 소비한 사용량을 보존합니다.
- 단일 작업·비교 실험·묶음 실행이 동시에 모델을 호출하지 않도록 실행 잠금을 공유합니다.
- 토큰 기준 때문에 남은 재시도를 실행하지 못한 실험은 완료나 유효한 절감률로 표시하지 않습니다. 손상·음수·범위 초과 사용량을 거부합니다.
- CLI 입출력 실패와 시간 초과 시 자식 프로세스를 정리하며, 로컬 서버의 외부 Host 요청을 차단합니다.
- Java 21, Electron의 Node 런타임, Codex CLI가 포함됩니다. 앱 메뉴의 Codex 구독 로그인으로 사용하며 API 키를 입력할 필요가 없습니다.
- Windows x64 설치형과 포터블을 제공합니다. 파일은 코드 서명되지 않았으며 SHA256SUMS.txt로 확인할 수 있습니다.

묶음 실행은 반복 문맥을 줄이는 기능입니다. 개별 작업의 effort 선택 성능 개선과 구분해서 평가해야 합니다. 문제당 각 방식 한 번씩 실행한 합성 문제 결과이므로 다른 작업의 정확도를 보장하지 않습니다. 데모는 동작 확인용 시뮬레이션이며 실제 절감 성과의 근거가 아닙니다. README와 실측 기록에서 완료 여부, 정답률, 전체 토큰을 함께 확인하세요.

토큰 중단 기준은 호출 사이에 확인하므로 마지막 호출만큼 초과할 수 있습니다. 사용량을 알 수 없는 호출이 있으면 표시된 합계를 전체 비용이나 절감률로 해석할 수 없습니다. 설치 파일에 사용자 계정, 자격 증명, 실험 DB는 포함하지 않습니다.
