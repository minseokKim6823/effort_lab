# 묶음 처리 실험 계획

고정일: 2026-10-04. 이 문서는 새 모델 실행 전에 작성했다.

개별 effort 정책의 연구는 [추론 예산 연구](추론예산연구.md)에 정리한다. 본 실험은 **동일 high에서 공통 입력을 여러 독립 작업에 나누는 효과**만 측정한다.

- 모델: gpt-5.6-luna. CLI: desktop에 고정된 0.153.4. 별도 API 키 없이 기존 ChatGPT 로그인 사용.
- 조건: 두 비교군 모두 high, answer-only-v1, 같은 JSON 응답 형식, 도구 비활성화.
- 데이터: 12개 알려진 합성 유형 × seed 20260927/20260928 = 새 인스턴스 24개. [고정 데이터](../results/v3/cases.json).
- 데이터 SHA-256: `106d39c2fee74d8e6e49423256b116fe2214faf5488a4b2e0f72fcc2cf1856a4`.
- 비교군: SINGLE_HIGH는 24개를 한 개씩, BATCH_HIGH는 연속 4개씩 6묶음으로 실행한다. 총 30회 모델 호출.
- 순서: 그룹 0·2·4는 개별 먼저, 그룹 1·3·5는 묶음 먼저. 같은 그룹의 작업 순서는 동일하다.
- 정답: 모델에 보내지 않는다. 생성 후 정확한 문자열 일치로만 채점한다. 오류·오답 재호출 없음.
- 중단 기준: 전체 알려진 총토큰 200,000. 호출 사이에 확인하며 마지막 호출만큼 초과할 수 있다.
- 실패: JSON 형식 오류, ID 누락·중복, 도구 사용도 실패로 기록한다. 사용량 누락이나 미완료가 있으면 전체 절감률을 확정하지 않는다. 원본과 이미 발생한 비용을 보존한다.
- 평가: 입력+출력 총토큰, 캐시 입력, 추론 토큰, 모델 호출 시간, 두 방식 모두 정답/개별만 정답/묶음만 정답/둘 다 오답. 배치 비용을 항목별 실측 비용처럼 나눠 적지 않는다.
- 한계: 24개의 합성 인스턴스, 각 비교군 1회다. 일반 업무·긴 출력·다른 모델에 대한 보장이나 구독 한도 절감률이 아니다.

[Batch Prompting](https://aclanthology.org/2023.emnlp-industry.74/)의 공통 입력 공유와 [BatchPrompt](https://arxiv.org/abs/2309.00384)의 위치·순서 민감성 관찰을 참고했다. 논문의 앙상블이나 내부 모델 학습을 구현했다고 주장하지 않는다.

실행 시 [measure-batch.mjs](../scripts/measure-batch.mjs)가 데이터·소스·실행 JAR 해시와 호출 순서를 manifest에 먼저 기록한다. 기존 manifest는 덮어쓰지 않는다. 완료 뒤 [audit-batch.mjs](../scripts/audit-batch.mjs)가 원본 JSONL과 API 결과를 독립적으로 대조한다.
