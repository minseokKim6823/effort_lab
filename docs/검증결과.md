# 개발 검증 결과

검증일: 2026-09-22

| 구분 | 결과 |
|---|---|
| Spring Boot Java 컴파일 및 실행 JAR 생성 | 성공 |
| 백엔드 자동 테스트 | 21개 통과 |
| 프론트엔드 단위 테스트 | 2개 통과 |
| TypeScript 검사 및 Vite 배포 빌드 | 성공 |
| Chrome 브라우저 E2E | 5개 통과 |
| 실제 Codex 구독 실행 | 36회 완료 |

| Windows 실행 스크립트 구문 | 정상 |

## 검증한 주요 동작

- 짧은 변환 작업의 low 선택, 정확도 우선의 high 선택
- 모호한 짧은 문제를 길이만으로 low로 처리하지 않음
- 검증 실패의 단계별 재시도와 최대 3회 종료
- 실패한 시도의 입력·출력 비용 포함
- 추론 토큰을 총토큰에 중복 가산하지 않음
- 검증 기준이 없는 답을 정답으로 집계하지 않음
- 사용량 누락을 무료 성공으로 처리하지 않음
- 불완전 응답 및 예상하지 않은 도구 사용 처리
- 실험 결과의 DB 저장과 재조회
- 잘못된 HTTP 입력과 외부 Origin 거부
- 데스크톱 화면의 분석·effort 변경·결과 원문 조회
- 390px 모바일 화면의 가로 넘침 없음
- 데모 모드의 실행과 정답 표시

실제 모델 호출에서 관측된 재시도는 0회다. 재시도 로직은 실패 응답을 주입한 자동 테스트로 검증했으며 실제 벤치마크에서 재시도가 발생한 것처럼 표현하지 않는다.

## 실행한 명령

```text
backend/gradlew.bat test bootJar --no-daemon --console=plain
frontend: npm test
frontend: npm run build
frontend: npm run test:e2e
node scripts/run-measurement.mjs
node scripts/audit-results.mjs
node scripts/write-report.mjs
```
